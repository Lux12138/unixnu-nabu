## 为什么保留

唯一的价值是**追溯**：为什么当初选了某条路、踩过哪些坑、哪些方案被否证过。

## 路线变更：xnu-8796 → xnu-10063

早期对比了两个已经跑通的 nabu 移植项目，它们都用 **xnu-8796（iOS 16 世代）**：

| 项目 | 内核 | 成果 |
|---|---|---|
| `glebenekt/ios-nabu` | xnu-8796 | 83 个 patch / 1.58 MB，launchd / SpringBoard / backboardd 启动 |
| `oosexgang/hackios` | xnu-8796 | 单文件 119 KB，锁屏/桌面/设置/Safari 可用 |

**但本项目最终选择 xnu-10063.141.1（iOS 17 世代）**，理由是目标用户态是
iPadOS 17.7.11 (21H461)，与 10063 匹配。

这个选择意味着 `xnu-8796/patches/` 那 86 个补丁全部作废——
它们基于 iOS 16 世代的内核结构，不能直接套用。

现行补丁序列见 `../../patches/xnu/series`（23 个，编号 0001–0017），
`board.toml` 的 `patch_series` 明确指向那里。
